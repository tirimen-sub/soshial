# 売上をスプレッドシートに集める（GAS）

レジ・セルフレジで買われた記録を、来場者全員分まとめて1つのスプレッドシートに集める設定です。
設定しなくてもレジは動きますが、その場合は記録がそれぞれの端末の中にしか残りません。

## 設定のしかた

1. Google スプレッドシートを新しく作る（名前は自由。例：「ソシアル製薬 売上」）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある内容を消して、このフォルダの `Code.gs` の中身を貼りつけて保存する
4. 右上の「デプロイ」→「新しいデプロイ」
   - 種類：ウェブアプリ
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
5. 初回は Google アカウントの許可を求められるので、許可する
6. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピーする
7. `register/config.js` の `SALES_ENDPOINT = ''` の `''` の中に貼りつけて、push する

買い物が行われると、スプレッドシートに「売上明細」シートができて1商品1行で記録されます。
商品登録画面の「全体の集計を読み込む」で、全員分の販売数ランキングを見られます。

## 注意

- `Code.gs` を直したときは、「デプロイを管理」→ 編集 → バージョン「新バージョン」で更新する（URL は変わらない）
- URL を知っている人は誰でも記録を送れるので、展示が終わったらデプロイを無効にしておくと安心
